# 繁簡閱讀：優化評估（patch.3）

## 已實作

- **雙向只從原文轉換**：避免繁→簡→繁的資訊損失累積；原文複製永遠使用選取快照。
- **按方向延遲初始化**：未使用簡體時不建立簡體轉換 trie；不等於延遲下載，字典仍打包在本機 artifact。
- **單次閱讀快取**：同一份原文的繁／簡結果只計算一次，切換更省工作；關閉釋放，不跨對話保存。
- **精確字典打包**：只匯入必要 core、四個方向模組與對應字典，避免整套日文／香港／台灣詞彙 preset。保留 OpenCC 1.3 的詞組分段，不以「較小但轉錯」交換效能。
- **過期選取防護**：待啟用快捷列再次驗證節點連接、選取端點、原文及保護狀態，防止讀到換頁／換選取前的文字。
- **鍵盤與焦點**：快捷列支援方向鍵／Home／End／Escape；面板切換後焦點回內文；右鍵出現快捷列時不搶焦點。
- **測試品質**：以真正 React／Edge 驗證互動，取代舊的手工 hook／dialog 模擬；加入上游雙向結果一致性與來源過期案例。

## 建議下一步（尚未實作）

| 優先序 | 項目 | 判斷與邊界 |
| --- | --- | --- |
| 高 | Desktop 官方原生選單擴充 API | 目前無追加原生項目的公開介面。應由上游提供帶卸載生命週期的 contribution API，再把兩個閱讀動作放進原生選單；不要直接修改 Electron 主程式或用私有 IPC。 |
| 高 | 實際 Desktop 的選單並存驗證 | 現有獨立瀏覽器測試不包含登入中 Electron 原生 popup。優先確認原生 Copy 仍可用、關閉 popup 後快捷列仍可操作、快捷列沒有遮住原有按鈕。 |
| 中 | 可關閉右鍵提示的偏好 | 可在未來加公開設定；只保存布林偏好，不保存原文。Shift＋右鍵已有單次略過方式，故不是本版必要功能。 |
| 中 | 可設定快捷鍵／位置 | 先查公開快捷鍵介面與衝突；位置需以實際窄視窗、主題與 Hot Restart 共存結果決定，不預設覆蓋其他按鈕。 |
| 低 | 更完整的技術片段辨識 | 先加真實誤轉案例的測試，再擴充解析器。任意未標記中文名稱無法完美辨識，不能宣稱全自動保護。 |
| 低 | Worker／分塊／按需字典載入 | 目前有 20k 字元上限。未測得可感知卡頓前不增加 IPC、資產載入、錯誤恢復或額外 runtime 依賴。 |

## 不建議

- 整頁 MutationObserver 取代文字、攔截所有複製事件、保存使用者內文快取。
- 取消原生右鍵或搶焦點開第二個 popup，假裝是原生選單追加功能。
- 為閱讀功能升級／移除 Codex、TUI、Mnemon、Context 或修改 Desktop 的依賴解析。

## 建置尺寸實測

上一版 Client 為 2,292,503 bytes；本版雙向轉換加快捷列為 2,342,023 bytes，增加 49,520 bytes（約 2.16%）。這不是「整個成品變小」；精確匯入是避免加入簡體方向時順便打包其他無關 preset。套件 dry-run 約 612.6 kB 壓縮，沒有新增 profile 執行期依賴。未做目標機長時間效能分析，不宣稱固定延遲提升。

## 評估依據與限制

依據目前 Desktop 0.2.1-rc.5 的原生右鍵處理、Client 公開 Service 目錄、程式審查、32 項單元測試及獨立 Edge／React 測試。不是對所有 Desktop 版本或所有第三方外掛的保證；實際上游 API 與版本變更需重新檢查。
