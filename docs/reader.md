# 繁體閱讀面板（1.0.1-patch.2）

## 使用方式

1. 在原頁反白一段一般內文（聊天、外掛頁面皆可）。
2. 按右下角的 **繁體閱讀**；位置在 Hot Restart 按鈕上方。
3. 面板以繁體顯示這次選取的文字，可切換 **原文／繁體**。
4. **複製原文**會複製反白時的原始字串。直接在面板反白並複製，則是面板當下顯示的文字。
5. 按 **關閉**或 Escape 關閉，清除面板持有的原文與顯示結果。

這是使用者確認的「獨立閱讀面板」方案，**不是整頁自動改寫或原地翻譯**。現有主介面／外掛字典繁體化仍正常運作。

## 原文與隱私界線

- 只有按下開啟按鈕時讀取目前選取範圍；不持續監視選取、不掃描整頁。
- 原頁 DOM、歷史、記憶、任務、模型輸入、原有複製／匯出功能都不改。
- 不呼叫模型、不送網路、不讀剪貼簿；OpenCC 核心與字典內嵌於套件，在本機頁面執行。
- 內容只留在目前 React 元件的記憶體，不存檔、不放入 localStorage／sessionStorage、不寫入日誌或設定。關閉／卸載會釋放引用，不代表可對瀏覽器記憶體進行安全抹除。
- 面板明文顯示你主動選取的內容；分享螢幕或截圖時仍須留意敏感資訊。
- 面板與入口不參與列印。截圖仍可拍到可見面板，並不保證視覺匯出是原文。

## 保護範圍與限制

- 拒絕位於或跨越輸入／編輯區、程式碼區塊、連結與明確敏感標記的選取；不嘗試修改那些元件。
- 選取上限 20,000 個 UTF-16 字元，超過時不截斷，要求縮小範圍。
- 面板轉換會保留可辨識的 Markdown 程式碼、參數、URL、路徑與常見命令列。
- **任意未標記的識別名稱／指令無法完美辨識**，例如一段普通中文同時可能是檔名或自然語句。這種內容請使用原文模式及「複製原文」。面板不承諾全自動識別所有技術文字。
- OpenCC 使用 `cn → tw` 字形／詞義轉換，不套用主介面用語替換表，避免對引用內文做額外改寫；仍可能遇到多義詞判斷差異。原文永遠可切換。
- 只處理明確選取的文字，不處理圖片、Canvas、PDF 畫布、原生 OS 選單或另一個 iframe 的內容。
- 顯示為純文字，不執行 HTML、Markdown 外掛、連結或程式碼。

## 驗證

自動測試涵蓋：無點擊不讀選取、範圍上限、保護區拒絕、原文字串保留、技術 token 保留、多行程式碼、開啟／切換／複製原文／關閉清除、註冊卸載，以及既有 65 個語系命名空間的回歸。

另外已在獨立 Edge + React StrictMode 測試環境驗證真實 DOM 選取、點擊開啟、切換、Escape／焦點還原、關閉清空、程式碼／編輯區／input 拒絕、自訂元素不被複製、剪貼簿延遲／拒絕提示、離線轉換、窄視窗與元件卸載。測試替換剪貼簿 API，不讀寫作業系統剪貼簿；深淺主題只做 media 切換可用性檢查，不宣稱已目視確認主題配色。

```sh
# 使用本機已安裝的 Microsoft Edge；不啟動測試伺服器
node tools/browser-smoke.mjs --fixture
```
