# 繁簡閱讀面板（1.0.1-patch.3）

## 三種使用入口

1. **閱讀按鈕**：原頁反白一般內文，按右下角 **繁簡閱讀**（Hot Restart 上方），可切換 **原文／繁體／簡體**。
2. **原頁右鍵**：在反白文字範圍內按右鍵，右下角另顯示 **轉為繁體閱讀／轉為簡體閱讀** 快捷列。
3. **面板右鍵**：在已開啟且有內容的閱讀面板內按右鍵，面板內另顯示 **原文／繁體／簡體** 切換列。

**這些不是原生右鍵選單項目。** Desktop 0.2.1-rc.5 的原生選單未提供外掛追加介面；本版不修改 Electron／Desktop 主程式，不取消或替換原生選單，也不搶焦點。原本的「複製」等仍可用；原生選單收起後可操作閱讀快捷列。**Shift＋右鍵**只用原本選單；其他外掛已處理的原頁右鍵事件也不攔截。

- 快捷列支援 Tab、方向鍵、Home／End、Enter／Space、Escape。選擇面板模式後焦點回到內文。
- 原頁快捷列會在點擊外部、捲動、視窗縮放、頁面隱藏、收起或開啟面板時清除。按下轉換前重新驗證來源節點、範圍、原文和保護狀態；來源改變就拒絕使用舊快照。
- 面板內的右鍵列可收起；Escape 優先收起該列，再按 Escape 關閉面板。
- **複製原文**保留反白當時的字串；直接反白面板文字複製，得到當下顯示版本。
- 按 **關閉**或 Escape 關閉面板，釋放原文及雙向顯示快取。

本功能是獨立閱讀，不是整頁改寫或原地翻譯。既有主介面／外掛字典繁體化不受影響。

## 隱私與保護界線

- 只有開啟、原頁右鍵及啟用相應快捷動作時讀取選取範圍；不持續掃描整頁、不監視選取變動、不使用 MutationObserver。
- 原頁 DOM、歷史、記憶、任務、模型輸入、原有複製／匯出功能不改。
- 不呼叫模型、不傳網路、不讀剪貼簿；OpenCC 核心及字典已內嵌，在本機頁面處理。
- 內容只在目前 React 元件的記憶體。待操作快捷列短暫持有來源節點以驗證是否過期；開啟面板後只保留原文字串，不持有來源節點。
- 不存檔、不放 localStorage／sessionStorage、不寫日誌／設定。關閉、收起、卸載釋放相應引用，不代表安全抹除瀏覽器記憶體。
- 拒絕輸入／編輯區、程式碼、連結及明確敏感標記的選取；上限 20,000 UTF-16 字元及 5,000 個檢查節點，不截斷資料。
- 可辨識的 Markdown 程式碼、參數、URL、路徑及常見命令列保持原樣。**未標記的任意識別名稱／指令無法完美辨識**，有疑慮請使用原文與複製原文。
- 繁體使用 `cn → tw`，簡體使用 `tw → cn`，保留上游詞組分段；每次都從原文產生，不把顯示結果再反向轉換。繁簡轉換可能有多義詞差異，且不保證可逆。
- 只顯示純文字，不執行 HTML／Markdown 外掛／連結／程式碼；不處理圖片、Canvas、PDF 畫布、OS 選單或另一個 iframe。
- 面板、入口、快捷列不參與列印，但螢幕分享／截圖仍可能包含可見內容。

## 驗證界線

32 項單元測試涵蓋靜態字典回歸、兩方向與上游轉換器的一致性、技術 token、範圍保護、原文保留及座標條件。既有 65 個靜態字典命名空間之外，閱讀器使用自己的 `lang-zhtw-reader` UI 命名空間。

```sh
npm test
# 本機已安裝 Microsoft Edge；不啟動伺服器、不需要 Desktop 憑證
node tools/browser-smoke.mjs --fixture
```

獨立 Edge + 真正 React StrictMode 已驗證兩處快捷列、三模式、未取消 contextmenu、未搶焦點、Shift／既有事件／保護區略過、舊選取／來源替換拒絕、鍵盤焦點、對話框關閉／清空、延遲／拒絕剪貼簿、離線、窄視窗及卸載。剪貼簿以測試替身取代，不讀寫 OS 剪貼簿；主題 media 切換不是目視配色驗證。

**以上不是登入中 Desktop 或 Electron 原生右鍵彈窗的完整端到端驗證。** 獨立瀏覽器登入受限，不取用／繞過憑證。需在實際 Desktop 人工確認：兩處快捷列與原生選單並存、收起原生選單後可點擊、實際位置、主題及跨應用程式貼上。Slot active／安裝成功不等於所有互動已驗證。
