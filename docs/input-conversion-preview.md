# 輸入框原地繁簡轉換候選版

**尚未安裝或推送。** 本工作區候選版為 `1.0.1-patch.3.input.1`，分支 `patch/input-conversion`。

目標是在聊天輸入框按右鍵，直接選擇轉繁體或簡體：有反白只轉選取部分，沒有反白則轉整份草稿。正常轉換可一次復原；不自動送出、不更動歷史訊息，保留附件及原子檔案／命令標籤。

需三部分配套：Desktop 原生選單橋接、編輯器新增的原子轉換介面、此語言包。單獨安裝語言包不會修改 Desktop，也不會啟用缺少橋接的功能。

詳細補丁、測試及尚未驗證事項見 repo 的[工作區交付說明](<../native-input/README.md>)。該開發工作區不包含在語言包 npm 成品內，因此連結須從 repo 開啟。

已完成隔離測試，**不代表已安裝 Desktop 的原生 popup／完整 GUI 已驗證**。封裝、簽章、實機操作及回復流程仍須確認；套用與重啟需另行同意。
